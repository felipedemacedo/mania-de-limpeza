## 🚀 Como Colaborar (Passo a Passo)

Quer contribuir com o projeto? É muito simples! Siga este passo a passo rápido para enviar suas alterações via **Pull Request (PR)**:

### 1. Fazer um Fork
No topo superior direito desta página do GitHub, clique no botão **Fork** para criar uma cópia deste repositório na sua conta.

### 2. Clonar o Repositório
Abra o seu terminal e clone o repositório que você acabou de forkar (substitua `seu-usuario` pelo seu nome de usuário do GitHub):
```bash
git clone https://github.com/seu-usuario/maniadelimpeza.git
cd maniadelimpeza
```

### 3. Criar uma Branch
Crie uma branch própria para as suas alterações:
```bash
git checkout -b minha-nova-melhoria
```

### 4. Fazer as Alterações e Commitar
Faça as modificações necessárias nos arquivos do projeto. Depois, adicione e salve as alterações com uma mensagem descritiva:
```bash
git add .
git commit -m "Explique brevemente o que foi feito"
```

### 5. Enviar as Alterações (Push)
Envie a sua branch para o seu repositório no GitHub:
```bash
git push origin minha-nova-melhoria
```

### 6. Abrir o Pull Request (PR)
1. Vá até a página original do repositório no GitHub.
2. Você verá um aviso sugerindo criar um Pull Request para a branch que acabou de enviar. Clique em **Compare & pull request**.
3. Escreva uma breve descrição do que você fez e clique em **Create pull request**.

Pronto! Sua contribuição será analisada e mesclada ao projeto principal. Obrigado por colaborar! 🎉
